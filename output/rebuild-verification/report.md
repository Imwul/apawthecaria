## 실제 브라우저 시나리오

검증 전용 JSON 파일을 로컬 앱 UI로 가져와 검사했다. 외부 서비스나 실제 사용자 캠페인을 수정하지 않았다.

1. 준비 도구 없는 가방에서 금잔화 CRUSHED Petals가 선택·획득 가능하며 ‘조제 때 필요’ 안내가 표시된다. Forest/Spring 채집10의 Alluring Odours에서 추가 K를 입력하고 Beech 보너스를 선택했다. 8시간→5시간은 조우−1/인접채집−2, 달력은1일 그대로다. 저장한 추가 카드로 재개 시 중복 획득 없이 완료했다.
2. Forgeclawed 요구 BURN1/WOUND1에 Marigold BURN2와 Maggots WOUND3, 절구를 선택했다. 빈 메모로 진행하고 Trading을 확정했다. 부위별1회분이 소비되고 명성+1/장신구+1, 기한8시간이 보존됐다.
3. 여분채집을 하지 않고 Moving On을 완료했다. 달력은1일로 유지된다. Odoak↔Obridge의 연결3경로로 이동력을 채우고 도착 사회 조우를 빈 메모로 완료했다. 위치Obridge·달력2일·다음 현지 진료 의무를 확인했다.
4. 조사↔조제 전환, 현재 패널 접기/다시 열기에서 선택한 부위가 유지되고 aria-expanded가 실제 펼침 상태와 맞는다.
5. 도감의 환자·현재지역·계절 동시 필터와 환자 진단/채집 원문 바로가기를 확인했다. 원문 뒤 닫기에서 상태·초점이 복귀한다.
6. 진료 마감 메모는 본문 위치 `static`, 기본 닫힘이다. 메모 없이 마감하고 출발 작업대에 바로 접근한다. 직접획득의3시간/4시간 목록은 둘 다 닫혀 있고 출발 버튼은 하나다.

## 남은 한계

실제 사용자 인터뷰/장기간 캠페인/모든 Almanack 예외의 브라우저 플레이는 수행하지 않았다. 핵심 절차와 선정 시나리오, 전체 기존 자동 회귀를 검증했다. 룰북의 Summer Loch 중복 rank10, 동률 지시 누락 등 모호성은 독립 분석에 남겼고 임의로 교정하지 않았다.

빌드는 성공하지만 App 청크가 약2.6MB(압축 약0.67MB)여서 번들 크기 경고가 남는다. 이번 검증은 접근 구조·판정 순서·반응형 사용성에 대한 것이며 저사양 기기의 최초 로딩 성능을 보장하지 않는다. 배포나 커밋은 요청 범위에 포함하지 않았다.

## 로컬 실행 환경

기존 iCloud 의존성 폴더의 지연 읽기로 서버가 멈추어 선언된 의존성을 다시 구성했다. package.json과 lockfile은 바꾸지 않았다. 원래 의존성 폴더는 같은 iCloud 상위 경로의 `.apawthecaria-dependencies-backup-20261008`에 보존했고 프로젝트의 node_modules는 정상 로컬 폴더다. 검증 브라우저의 테스트 캠페인은 처음의 이름 없는 상태로 되돌리고 임시 탭과 뷰포트를 정리했다.
