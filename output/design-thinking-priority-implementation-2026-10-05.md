# Design Thinking: 상 우선순위 구현과 색면 보완

Date: 2026-10-05
Baseline: 5bf8b795fec24cd8f021f2dc7acad42de5830375

## Empathize

사용자는 이전 검토의 상 항목부터 수정하되 중·하 옵션도 고려하도록 요청했다. 주 사용 환경은 3440×1440이며 작은 글씨, 노션 같은 반복 양식, 강한 장식, 선화, 금색 A 인장은 선호하지 않는다. 작업 중 자신이 만든 Reference Desk의 인상을 참고하고 더 대담한 색을 넣어 달라는 추가 피드백을 주었다. 이어서 블록 자체를 따라 하거나 여러 색으로 가득 채운 블록은 싫다고 명확히 정정했다. 최종안은 이 최신 피드백을 우선한다.

BMAD Design Thinking과 Party Mode의 Maya(행동 동선), Caravaggio(공간·화풍), Sophia(현재 서사) 관점으로 수렴했다. 설치된 스킬의 기본 워크플로를 사용했으며 별도 에이전트나 실제 사용자 테스트를 수행했다고 주장하지 않는다. 사용자 위임에 따라 구현과 확인을 연속해서 진행했다.

## Define

큰 글씨와 넓은 종이를 유지하면서 카드 선택, 결과, 다음 행동의 시선 이동을 줄인다. 왼쪽 면은 현재 모험에 필요한 정보를 담고, 주요 행동은 색으로 식별할 수 있어야 한다. 화풍과 색면은 서로 경쟁하지 않아야 한다.

## Ideate

기존 design-thinking-design-refinement 문서의 아이디어와 우선순위를 바탕으로 다음을 선택했다.

- 카드 옆에 결과와 동물 선택을 배치하고 그 아래 단계 이동을 모은다.
- 이름·외형에 지속적으로 보이는 라벨과 적절한 길이의 입력란을 둔다.
- 현재 환자의 필요한 약효, 행선지, 최근 일지를 왼쪽 면의 메모로 사용한다.
- 선택 메모는 접어두고, 실제 선택이 완료된 단계만 체크한다.
- 풍경을 기존 동물·식물 삽화와 같은 부드러운 수채 질감으로 맞춘다.
- Reference Desk에서 여백, 분명한 구획, 큰 타이포의 대비를 참고한다. 강한 색은 숲색 한 계열로 제목·주요 행동·선택 표시에 제한한다.

중·하 항목 중 타이포 위계, 실제 상태를 반영한 체크 표시, 카드가 놓이는 짧은 반응을 이번 범위에 포함했다. 장별 구조의 추가 분화, 계절 장식, 아이콘 전체 교체는 이번에 완료했다고 보지 않는다.

## Prototype

상 항목 네 가지를 실제 React/CSS에 적용했다.

1. **행동 거리와 정렬:** 2800px 이상에서 약제사·길동무의 카드와 선택을 나란히 둔다. 좁은 화면에서는 순서대로 쌓는다. 결과는 왼쪽 정렬하고 다음 행동은 같은 작업 면 바로 아래 둔다.
2. **왼쪽 면의 역할:** 지도는 현재 위치·목적지·목표, 약초와 병증은 환자와 필요 약효, 배낭은 약제사·길동무·약재, 이야기는 최근 기록 일부를 표시한다. 현재 게임 상태를 읽기만 하며 별도 저장 상태를 만들지 않는다.
3. **주요·보조 조작:** 주요 카드 뽑기와 다음 행동은 채운 숲색, 보조 입력은 외곽선이다. 고정 라벨, 짧은 입력란, 완료 단계 체크, 선택 메모 펼침을 적용했다. 큰 글씨를 잘라내던 선택 상자의 높이도 늘렸다.
4. **화풍:** 새 woodland-path-watercolor.webp를 첫 기록·모험·지도에 사용했다. 내장 image generation 도구에 기존 woodland-herbarium.webp와 woodland-whimsy.webp를 스타일 참고로 제공했다. 원본 PNG는 보존하고 알파를 유지해 WebP로 변환했다. 전체 프롬프트는 public/art/woodland-path-watercolor.prompt.md에 저장했다.

최신 피드백에 따라 생성 머리말·현재 메모·모험 행동 묶음·필터에 큰 색 배경을 두지 않는다. 아이보리 면, 숲색 제목과 얇은 구분, 주 행동의 채움으로 강조를 제한했다. 현재 장 탭만 숲색으로 명확하게 표시한다.

## Test

- 3440×1440: 본문 26px, 입력 23px 유지. 약제사 선택을 완료한 단계의 다음 버튼 하단은 약 1150px로 첫 화면 안에 있다. 기존 비교 화면에서는 약 1379px였다.
- 3440×1440과 390×844에서 아홉 장 이동 및 문서 가로 넘침 0px 확인. 1440×1000 생성 화면에서도 가로 넘침 0px 확인.
- 생성 8단계 이동, 카드 뽑기 후 실제 완료 체크, 선택 메모 입력, 새로고침 후 메모 복구 확인. 길동무 단계의 두 details가 같은 행에 겹치지 않도록 분리했다.
- 모바일 생성 바로가기는 작성 면에 초점을 옮긴다. 머리말의 초기화 버튼이 세로로 잘게 줄바꿈되던 것을 한 줄로 수정했다.
- 현재 환자의 WOUND 2 / PAIN 1 표시가 오래된 legacy 병증을 사용하지 않는지, 완료된 여정에 이전 목적지가 남지 않는지, 최근 일지에 activity 기록이 섞이지 않는지 검사했다. 읽기 중 캠페인 상태가 변하지 않는 것도 확인했다.
- 프레젠테이션·생성·레이아웃 검사 56개, 규칙 검증 4개, 참조 검증 8개 통과. TypeScript, production build, 변경 TypeScript 파일 lint 통과. 기존 대형 청크 경고는 남아 있다.
- 숲색 활성 탭과 밝은 글씨의 대비를 확인한다. 전체 사이트 접근성 인증을 의미하지 않는다.
- 브라우저 검증 이미지는 이 채팅의 2026-10-05-refinement 시각화 폴더에 저장한다. 운영 배포 상태는 푸시 후 별도 확인해 최종 응답에 기록한다.

## Next steps

시각적 만족도는 아직 사용자의 새 화면 피드백을 받지 않았다. 다음 중 우선순위 작업은 지도·표본·편지의 공간 구성을 더 구별하고, 긴 기록을 읽는 폭을 다듬는 것이다. 낮은 우선순위 장식은 주요 행동의 집중과 글씨 대비를 해치지 않는 범위에서 추가한다.
