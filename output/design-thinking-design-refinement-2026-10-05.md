# Design Thinking Session: Apawthecaria 디자인 보완 검토

**Date:** 2026-10-05
**Facilitator:** Codex — BMAD Design Thinking / Party Mode의 단일 세션 관점 토의
**Design Challenge:** 3440×1440의 큰 글씨와 차분한 수첩을 유지하면서, 실제 게임 행동과 whimsical한 정서를 더 밀접하게 연결한다.

## Design Challenge

사용자는 전면 개편 이후 디자인적으로 보완할 점을 물었다. 이번 범위는 평가와 개선 제안이다. 현재 배포 첫 화면, 같은 커밋의 일지 화면 캡처, 장별 삽화와 레이아웃 코드를 근거로 검토했다. 새 디자인을 구현하거나 사용자 테스트를 수행했다고 주장하지 않는다.

## EMPATHIZE: Understanding Users

### User Insights

대화에서 확인한 선호: 3440×1440, 큰 글씨, Instrument Serif 영문과 좁은 자폭의 한글, 차분한 숲과 아이보리, 회화적인 장식. 강한 장식·금색 A 인장·선으로만 그린 손그림·노션 같은 반복 양식은 선호하지 않는다.

### Key Observations

- 실제 배포 첫 화면의 수첩 폭은 2680px, 왼쪽 소개 면은 약 884px이다.
- 작업 본문은 x=1575 부근, y=533 부근에서 시작한다. 이름 입력 폭은 1100px이다.
- 카드 뽑기 버튼은 y=868, 다음 버튼은 y=1319에 있다. 화면 전체를 축소하지 않고 공간 배분을 개선할 여지가 있다.
- 카드 해설·동물 안내는 서로 다른 정렬을 사용한다. 두 이름/종류 입력란은 placeholder가 중심이다.
- 첫 풍경은 구아슈 색면에 가깝고 표본·편지 삽화는 세밀한 수채 물체 묘사에 가깝다. 이는 시각적 평가이며 사용자가 불일치로 느낀다는 검증은 아직 없다.
- 약초·병증·자료실·발견이 같은 식물 삽화를 공유한다. 장별 차이가 생겼지만 네 장의 반복은 남아 있다.
- 일지의 편지와 줄 배경은 주제를 전달한다. 넓은 쓰기 면과 반복된 사각 기록 카드는 여전히 양식의 인상을 준다.

### Empathy Map Summary

- Says: 사이트 자체가 달라지길 원하며, 읽기 편하고 차분한 whimsical 분위기를 원한다.
- Thinks / Feels — 추론: 반복적인 외형 교체보다 게임의 세계가 느껴지는 일관된 경험을 기대한다.
- Does: 실제 화면을 보고 정렬·폰트·밀도·배포 상태를 구체적으로 피드백한다.
- Methods: 이전 발화에 기초한 User Interviews 자료 검토, Empathy Mapping, Journey Mapping. 실제 Shadowing은 수행하지 않았다.

## DEFINE: Frame the Problem

### Point of View Statement

넓은 모니터에서 혼자 플레이하는 사용자는 큰 글씨와 가까이 모인 행동을 필요로 한다. 설명과 장식의 점유 면적이 커도 실제 플레이의 집중과 이야기의 변화는 분명하게 보여야 한다.

### How Might We Questions

1. 글씨 크기를 유지하면서 행동 사이의 시선 이동을 줄일까?
2. 왼쪽 면을 반복되는 소개에서 현재 모험에 필요한 맥락으로 발전시킬까?
3. 약초, 편지, 지도 각각의 사용 방식에서 장난스러운 디테일이 생기게 할까?

### Key Insights

큰 여백, 회화, 책 모양 자체로는 플레이 경험이 충분히 바뀌지 않는다. 다음 단계는 읽는 순서와 조작의 결합, 장마다 다른 작업 방식, 상태에 연결된 작은 변화다.

## IDEATE: Generate Solutions

### Selected Methods

SCAMPER Design, Analogous Inspiration(표본첩·편지·여행 지도), Brainstorming, Affinity Clustering.

### Generated Ideas

1. 카드 뽑기·결과·동물 선택·다음을 한 작업 묶음으로 배치한다.
2. 첫 단계 설명의 위아래 간격을 줄인다.
3. 이름 필드를 짧게 하고 고정된 이름 라벨을 둔다.
4. 설명과 결과의 왼쪽 기준선을 통일한다.
5. 단계 색인에 완료·현재·미작성 상태를 구분한다.
6. 가장 중요한 카드 뽑기 행동을 진한 숲색으로 강조한다.
7. 큰 영문 장 제목과 한국어 실제 작업 제목의 위계를 조정한다.
8. 첫 소개 이후 왼쪽 면에 현재 행선지·환자·채집 목표를 보여준다.
9. 약초는 표본 목록과 펼친 표본을 중심으로 공간을 나눈다.
10. 일지는 읽기 폭을 제한한 편지 중심으로 구성한다.
11. 지도는 현재 고정된 장 소개 비중을 줄여 실제 지도를 넓힌다.
12. 풍경·동물·물건의 붓결과 명암 단계를 맞춘다.
13. 이모지를 면이 있는 작은 단색 아이콘으로 통일한다.
14. 버튼의 채움·외곽선·텍스트만 사용한 보조 행동에 역할을 부여한다.
15. 계절에 따라 한 곳의 작은 식물 장식만 변한다.
16. 발견한 표본이 목록에 들어오는 짧은 반응을 제공한다.
17. 일지 저장 후 실제 저장 상태와 연결된 책갈피 반응을 제공한다.
18. 카드 뽑기를 짧게 뒤집고 내려놓는 움직임으로 표현한다.
19. 글자 뒤를 피한 종이 가장자리와 미세한 안료 얼룩을 사용한다.
20. 긴 입력 중에는 주요 행동을 가까운 위치에 유지한다.

### Top Concepts

1. 가까이 모인 카드 작업 면 — 큰 글씨를 유지하며 행동을 연결한다.
2. 장마다 다른 펼침 — 지도·표본·편지가 동일한 소개+양식 비율에 갇히지 않게 한다.
3. 플레이에 반응하는 조용한 whimsical — 장식의 변화를 실제 발견과 기록에 연결한다.

Party Mode 관점 토의: Caravaggio는 공간과 화풍의 통일, Maya는 행동 사이 거리와 위계, Sophia는 발견·기록에 연결된 작은 서사적 반응을 강조했다. 토의 명단 자동 로딩이 비어 있어 이 세 관점으로 진행했다. 별도 에이전트를 실행하지 않았다.

## PROTOTYPE: Make Ideas Tangible

### Prototype Approach

다음 구현에서 비교할 Storyboarding 및 Paper Prototyping 수준의 구성을 제안한다. 이 문서의 내용은 구현 전 가설이다.

### Prototype Description

- 캐릭터 생성: 현재 단계 → 이름 → [카드 / 결과와 동물 선택] → 바로 아래 다음 행동. 긴 보조 설명은 가까운 펼침 안에 둔다.
- 약초: 읽을 수 있는 크기의 표본 색인 → 펼친 항목의 부위·약효·조제법. 한 항목이 작업의 중심이 된다.
- 이야기: 상단의 짧은 날짜·장소 → 너비를 제한한 편지 → 저장과 완료 표시. 지난 기록은 충분한 문장 미리보기를 갖는다.

### Key Features to Test

첫 행동의 발견, 단계 완료 경로, 큰 글씨의 유지, 긴 일지 읽기, 실제 상태와 장식의 구분.

## TEST: Validate with Users

### Testing Plan

현재안과 수정안을 3440×1440에서 나란히 비교한다. 사용자가 카드 한 장 뽑고 동물을 정하기, 특정 약초의 조제법 찾기, 지난 일지 읽기를 수행하도록 한다. 더 차분한지, 더 게임 같은지, 다음 행동을 찾기 쉬운지를 구분해 묻는다. 모바일에서도 주요 조작이 소개 뒤에 과도하게 밀리지 않는지 확인한다.

### User Feedback

이번 보완 제안에 대한 사용자의 피드백은 아직 없다. 기존 구현 검사 통과는 시각적 만족도를 입증하지 않는다.

### Key Learnings

현재안은 넓은 화면과 읽기 크기를 확보했다. 다음 개선은 그 공간에서 무엇에 집중하게 하는지와, 플레이 결과가 시각적으로 어떻게 남는지에 있다.

## Next Steps

### Refinements Needed

상: 행동 거리와 정렬, 왼쪽 면의 역할, 주요/보조 조작의 시각 위계, 삽화 화풍의 통일.
중: 장별 구성 차이와 긴 문장 읽기 폭, 타이포 위계, 상태에 연결된 작은 움직임.
하: 종이 가장자리·국소 질감·계절별 작은 장식.

### Action Items

먼저 캐릭터 생성 한 면에서 행동 동선과 버튼 체계를 다듬은 뒤, 약초와 일지로 확대하는 순서를 권한다. 현재 요청에 따라 검토 결과와 우선순위를 제시한다.

### Success Metrics

큰 글씨를 유지하면서 주요 행동이 가까이 모인다. 장을 바꾸었을 때 실제 작업 방식의 차이가 드러난다. 작은 반응이 정확한 저장·발견 상태를 전달하며, 장식이 읽는 글과 경쟁하지 않는다.
